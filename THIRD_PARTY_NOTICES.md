## Unicode data

`packages/text/src/unicode/data.generated.ts` is generated by `scripts/unicode/generate.mjs` from the Unicode Character Database 15.1.0 (LineBreak, EastAsianWidth, Scripts, DerivedCoreProperties (Indic_Conjunct_Break), GraphemeBreakProperty, emoji-data, DerivedGeneralCategory, PropertyValueAliases). `packages/text/test/fixtures/` holds subsets of the UCD test files LineBreakTest.txt, GraphemeBreakTest.txt and BidiCharacterTest.txt. ## Fonts

`fixtures/fonts/` holds subsets of fonts from the Google Fonts repository, all under the SIL Open Font License 1.1, each with its `OFL.txt`: Inter (The Inter Project Authors), Noto Sans, Noto Sans Arabic and Noto Sans Devanagari (The Noto Project Authors), and Noto Sans SC (Adobe; Reserved Font Name "Source", not used by the subset's name). `fixtures/fonts/README.md` lists the upstream files and what was kept. They are used by tests and by the editor's sample document; no font is bundled into the packages.

Module 5b (the vector toolkit in `packages/geometry`: curve intersection, booleans, vector networks, path editing, the pen tool, outline stroke, SVG path data) ports no code. Its algorithms come from public literature and specifications: Bézier clipping (Sederberg and Nishita, 1990), curve fitting (Schneider, Graphics Gems, 1990), and the SVG 1.1 arc implementation notes (Appendix F.6); the arrangement and winding-number booleans are our own. Penpot's boolean and path-editing code was read only for its test cases, which are ported as test data under MPL-2.0 (above). Penpot's arc conversion (`arc_to_bezier.js`, MIT, from fontello/svgpath) was not used. Module 5b adds no npm dependencies.

Module 2 (the document model) ports no Penpot code. It used Penpot's document invariants and component override model (`docs/reference/penpot.md` §1.3 and §1.9) only as a reference, to check that our schema leaves room for touched-group overrides.

Module 4 (the text engine, `packages/text`) is a clean-room implementation of CSS Text 3/4, CSS Inline 3, CSS Fonts 4, Unicode UAX #14 and UAX #29 and the OpenType and WOFF/WOFF2 specifications; shaping is HarfBuzz. Where Chromium's results differ from a literal reading of those specs (metric rounding, its tailoring of line breaking for ASCII punctuation), the behaviour was learned by rendering test cases in Chromium and comparing (`docs/conformance.md`), not from browser source.

Module 3 (the layout engine, `packages/layout`) is a clean-room implementation of the W3C specifications (CSS Box Model 3, CSS Sizing 3 and 4, Flexible Box Layout 1, Grid Layout 1, Box Alignment 3, Positioned Layout 3). No code from browser engines, Yoga, Taffy or Penpot was read or used. Penpot's flex and grid layout is Figma-style rather than CSS (`docs/reference/penpot.md` §1.4, §1.5) and was not ported. Where Chromium's behaviour differs from a literal reading of a spec, the behaviour was learned by rendering test cases in Chromium and comparing boxes (`docs/conformance.md`), not from its source. Module 3 adds no npm dependencies.
